# Pattern inspiration references

These images are design references, not assets used by the rendered patterns.
The production patterns are generated procedurally by Aperiodos.

## Einstein curves

- `curves.png` and `einstein-curves-reference.png`
- Source: supplied by the project owner as a visual reference.
- Design idea: a two-color, tile-local curve motif whose paths continue across
  neighboring tile boundaries.

## Penrose curves

- `rhomb_curves.png`
- Source: supplied in the project workspace as a visual reference.
- Design idea: circular arcs and small junction marks carried by Penrose rhombs.

- `penrose-floor-cc0.jpg`
- Source: [Penrose tiling at Oxford Mathematical Institute](https://commons.wikimedia.org/wiki/File:Penrose_tiling_at_Oxford_Mathematical_Institute.jpg)
- Creator: Pierre Marshall
- License: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
- Design idea: linework can cross tile boundaries and visually subordinate the
  individual tile fills.

## Spectre

The Spectre motif is original to this project. It combines a clipped inset echo
of the tile with a flowing accent stroke so the highly asymmetric silhouette
remains recognizable.
